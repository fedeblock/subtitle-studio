# MVP setup: plan y registro

Objetivo: reparar el MVP existente siguiendo la arquitectura solicitada el 2026-11-04.
Ejecución en el checkout indicado, rama feature/mvp-setup; sin reescribir historia ni borrar datos existentes.

## Diseño y decisiones

Se conservan FastAPI, SQLAlchemy, RQ, PostgreSQL, Redis y frontend estático. Docker aloja los cinco servicios; el gateway Python y Ollama siguen nativos para Metal. Se sustituye el CLI efímero por Session + ForcedAligner explícitos, propiedad de un solo hilo, carga bajo demanda y liberación a los 600 segundos desde el fin de la última inferencia. Ollama mantiene keep_alive=10m. No se descargan pesos durante el setup.

La alternativa de ejecutar un CLI por trabajo no cumple la retención requerida. Llevar MLX a Docker no cumple Metal en macOS. Se mantiene el gateway autenticado compartiendo data/ con Docker, con validación de rutas.
